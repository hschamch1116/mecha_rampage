# Mecha Rampage: Siege Walker V5

브라우저에서 실행하는 3D 메카 전투 프로토타입입니다. 격납고에서 장비를 구성하고 메카 외형을 조정한 뒤, 파괴 가능한 도시 전장에 출격해 적 8M Assault Platform과 교전합니다.

> 이 프로젝트는 별도 빌드 과정이나 패키지 설치가 없는 정적 웹 게임입니다. 게임 엔진과 후처리 모듈은 실행 시 CDN에서 가져옵니다.

## 주요 기능

- **3D 전장:** Three.js 기반의 도시 환경, 조명, 블룸 후처리, 미니맵 및 목표 거리 표시
- **메카 전투:** 양팔 무장, 조준 카메라, 탄도/유도 탄환, 반동과 피격 효과
- **장비 구성:** 격납고에서 4개 프리셋에 중포·개틀링·레이저·유도 미사일을 선택
- **적 AI:** 이동, 거리 조절, 사격, 유도 미사일, 보호막 및 체력 바로 구성된 보스형 적
- **기동 시스템:** 보행, 부스트, 점프/비행, 하강 및 에너지 소모
- **방어/피해 시스템:** 플레이어 실드, 부위 손상 HUD, 무기 쿨다운과 적 체력 표시
- **커스터마이즈:** 부위 선택, 크기/위치 조정, 색상 프리셋, 헤드 숨김 및 브라우저 저장
- **사운드:** 격납고 BGM과 기계 보행 효과음

## 빠른 실행

### Windows

프로젝트 루트의 `run-server.bat`을 더블 클릭하면 Python의 간단한 웹 서버가 실행되고 기본 브라우저가 열립니다.

또는 PowerShell에서 다음 명령을 실행합니다.

```powershell
py -m http.server 8080
```

`py` 명령이 없다면 아래를 사용하세요.

```powershell
python -m http.server 8080
```

브라우저에서 [http://localhost:8080](http://localhost:8080)을 엽니다. 서버 종료는 실행 중인 터미널에서 `Ctrl+C`를 누릅니다.

### 요구 사항

- 최신 Chromium 계열 브라우저(Chrome, Edge 등) 권장
- Python 3 — `run-server.bat` 또는 로컬 서버 실행용
- 인터넷 연결 — Three.js와 애드온 모듈을 CDN에서 불러오기 위해 필요

`index.html`을 직접 열어도 일부 환경에서는 동작할 수 있지만, 일관된 모듈/오디오 동작을 위해 로컬 서버 실행을 권장합니다.

## 플레이 흐름

1. 타이틀 화면에서 **ENTER HANGAR**를 선택합니다.
2. 격납고에서 슬롯 1~4에 원하는 무장을 지정합니다. 선택한 슬롯은 전투 중 숫자 키로 즉시 불러올 수 있습니다.
3. 필요하면 **CUSTOMIZE MECHA**에서 외형을 조정하고 저장합니다.
4. **BATTLE START**를 누른 뒤 게임 화면을 클릭해 마우스 포인터를 잠급니다.
5. 이동·조준·무장을 조합하여 적을 처치합니다.

## 조작법

| 입력 | 기능 |
| --- | --- |
| `W` `A` `S` `D` | 전후좌우 이동 |
| 마우스 이동 | 시점 및 조준 |
| `Shift` | 부스트 |
| `Space` | 지상에서는 점프, 공중에서는 상승/비행 |
| `Ctrl` 또는 `C` | 공중에서 하강 |
| 좌클릭 | 오른팔 무장 발사 (슬롯 2의 무장) |
| 우클릭 | 왼팔 무장 발사 (슬롯 1의 무장) |
| `1`–`4` | 해당 무장 프리셋 활성화 |
| `P` | 일시정지/재개 |
| `R` | 게임 재시작 |
| `V` | 워터 실드 테스트 — 실드를 100%로 회복 |

연사형 무장(개틀링/레이저)은 버튼을 누르고 있는 동안 발사하고, 중포와 유도 미사일은 클릭 한 번에 발사합니다. 게임 화면 밖을 클릭하거나 `Esc`를 누르면 포인터 잠금이 해제됩니다.

## 무장

| 무장 | 특징 |
| --- | --- |
| Heavy Cannon | 강한 충격과 구조물 파괴에 적합한 단발 포격 |
| Gatling | 근거리 제압에 적합한 빠른 연사 |
| Laser Cannon | 에너지를 소비하는 연속 사격 |
| Homing Missile | 여러 발을 산개 발사한 뒤 목표를 자동 추적 |

무장은 격납고에서 슬롯별로 선택합니다. 전투 중 `1`–`4` 키는 그 프리셋을 활성화하며, 활성 프리셋이 왼팔 또는 오른팔 장착 위치에 반영됩니다.

## 메카 커스터마이즈

격납고의 **CUSTOMIZE MECHA**에서 다음을 조정할 수 있습니다.

- 화면의 메카 부위를 클릭하거나 목록에서 부위를 선택
- 색상 프리셋 선택
- 선택 부위의 너비·높이·깊이와 X/Y/Z 위치 조정
- 헤드 숨김
- **SAVE**로 브라우저 `localStorage`에 저장
- **RESET**으로 저장된 커스터마이즈 삭제 후 기본값 복원

커스터마이즈 화면에서는 드래그로 메카를 회전하고, 마우스 휠로 확대/축소합니다. 저장값은 현재 브라우저의 로컬 데이터에만 보관되므로 브라우저 사이트 데이터를 지우면 함께 삭제됩니다.

## HUD 읽기

- **중앙 조준점:** 현재 사격 방향
- **좌우 무기 HUD:** 장착 무장 이름과 쿨다운/준비 상태
- **원형 Vitals:** 기체 체력과 에너지 실드 비율
- **부위 손상 HUD:** 특정 부위의 손상 상태
- **전술 미니맵:** 전장 내 위치, 방향 및 주변 위협
- **목표 거리:** 가장 가까운 적까지의 거리
- **적 체력 바:** 적 유닛의 남은 체력

## 프로젝트 구조

```text
.
├── index.html          # UI, 렌더링, 게임 루프, 플레이어/전장/무장 로직

├── mecha-character.js  # 플레이어 메카 외형 생성 로직

├── assets/

└── run-server.bat      # Windows용 로컬 서버 실행 스크립트
```

## 기술 구성

- JavaScript (ES Modules)
- [Three.js 0.169.0](https://threejs.org/) 및 Three.js 애드온
- `EffectComposer`, `RenderPass`, `UnrealBloomPass`, `OutputPass`
- HTML/CSS 기반 HUD와 격납고 인터페이스
- 브라우저 `localStorage` 기반 커스터마이즈 저장

## 개발 참고

- 외부 의존성은 `index.html`의 import map에서 `unpkg.com` CDN으로 로드됩니다.
- 현재는 정적 파일만으로 구성되어 있어 `npm install`이나 빌드 명령이 필요하지 않습니다.
- 게임 로직을 수정한 뒤에는 서버를 새로 고칠 때 브라우저 캐시를 무시하는 새로고침(`Ctrl+F5`)을 사용하면 변경 사항 확인에 편리합니다.
- 사운드 재생과 포인터 잠금은 브라우저 정책상 사용자 클릭 이후에 활성화됩니다.
