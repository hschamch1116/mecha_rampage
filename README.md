# Mecha Rampage: Siege Walker V5

브라우저에서 실행하는 정적 Three.js 3D 메카 전투 게임입니다. 타이틀의 지하 리프트 연출에서 시작해 격납고 무장 선택·메카 커스터마이즈·도시 전장 전투까지 하나의 흐름으로 구성됩니다.

> 빌드 도구나 패키지 설치가 필요 없는 정적 프로젝트입니다. Three.js 모듈은 CDN에서 가져오므로 처음 실행할 때는 인터넷 연결이 필요합니다. 오디오와 모듈 호환성을 위해 `file://`로 직접 열기보다 로컬 HTTP 서버 실행을 권장합니다.

## 빠른 실행

### Windows

프로젝트 루트의 `run-server.bat`을 실행하거나 PowerShell에서 아래 명령을 사용합니다.

```powershell
py -m http.server 8080
```

`py`를 사용할 수 없으면 다음을 사용합니다.

```powershell
python -m http.server 8080
```

그 다음 브라우저에서 [http://localhost:8080](http://localhost:8080)을 엽니다. 서버는 실행한 터미널에서 `Ctrl+C`로 종료합니다.

## 플레이 흐름

1. 타이틀에서 지하 원형 리프트가 상승하고 해치가 열립니다.
2. **ENTER HANGAR**를 누르면 해치가 열린 상태로 4슬롯 무장 선택 화면으로 이동합니다.
3. 필요하면 **CUSTOMIZE MECHA**에서 볼 조인트·파츠·색상·형상을 조정합니다.
4. **BATTLE START**로 도시 전장에 출격합니다.
5. 전투 중 무장을 전환하고 건물·차량·적 메카를 상대합니다.

## 주요 기능

### 타이틀과 격납고

- 원형 샤프트가 실제로 비어 있는 지하 리프트 연출
- 상부 고정 카메라에서 메카와 원형 플레이트가 아래에서 올라오는 장면
- 타이틀에서 열린 리프트 해치를 무기 선택 격납고에서도 유지
- 격납고 조명, 정비 로봇암, 수리 스파크, 증기와 대형 도크 구조물
- `RETURN TO TITLE`을 누르면 리프트·게이트·메카를 타이틀 초기 상태로 재설정

### 전투와 도시

- 보행, 부스트, 점프/비행, 착지 및 발 접지 보정
- 적 메카 AI, 픽업 추적, 방어막·부위 내구도·HUD
- 파괴 가능한 건물 블록, 유리창, 붕괴와 먼지 효과
- 차량, 나무, 가로등, 전장 반사·포스트 이펙트 설정
- 시야·건물 충돌 기반 조준 및 엄폐 판정

### 무장

| 무장 | 역할 |
| --- | --- |
| Heavy Cannon | 강한 직격 및 범위 피해, 구조물 파괴에 적합 |
| Gatling | 근거리 지속 연사 |
| Laser Cannon | 에너지를 소비하는 연속 사격 |
| Homing Missile | 다발 발사 후 목표를 추적하는 유도 미사일 |

호밍 미사일은 발사자 시야뿐 아니라 **각 미사일과 목표 사이의 경로**도 검사합니다. 목표가 건물 뒤로 숨으면 해당 미사일의 유도가 해제되며, 벽 뒤로 꺾어 추적하지 않고 현재 탄도로만 비행합니다.

### 커스터마이즈와 소켓

- 바디 색상 프리셋, 메쉬 치수·위치, 숨김 파츠 설정
- 백팩 1개, 양팔 2개, 서브 무기 2개, 하체 링크 1개의 바디 볼 조인트
- 좌·우 대칭 이동 옵션과 볼 조인트 크기 조절
- 선택한 볼 조인트를 숨기거나 다시 표시하는 체크박스(저장 후에도 유지)
- 슬롯 3/4 무기는 각각 좌·우 서브 무기 소켓을 공유
- 파츠를 선택하면 소유 볼 조인트가 선택되고, 조인트를 선택하면 연결 파츠가 즉시 동기화
- 모든 스냅은 `player` 로컬 → 월드 → 각 파츠 부모 로컬 변환을 거쳐 처리하므로 서로 다른 부모를 가진 팔·무기·백팩도 같은 좌표 기준으로 결합
- 백팩 조인트는 백팩 코어 중심을 기준으로 배치되며, 백팩 모델에도 중심 결합 조인트가 표시됨
- **SAVE**는 브라우저 `localStorage`의 `mechaCustomization`에 저장합니다. 게임을 다시 열면 자동 적용됩니다.
- **RESET**은 저장된 커스터마이즈를 삭제하고 기본값으로 돌아갑니다.

## 조작

| 입력 | 기능 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| 마우스 이동 | 시점 및 조준 |
| `Shift` | 부스트 |
| `Space` | 점프 / 공중에서 상승·비행 |
| `Ctrl` 또는 `C` | 공중 하강 |
| 왼쪽 클릭 | 오른팔 무장 발사 |
| 오른쪽 클릭 | 왼팔 무장 발사 |
| `1` ~ `4` | 무장 프리셋 전환 |
| `P` | 일시정지/재개 |
| `R` | 게임 재시작 |
| `V` | 1인칭/3인칭 시점 전환 |

레이저와 개틀링은 버튼을 누르는 동안 연사합니다. 캐논과 호밍 미사일은 클릭 1회에 발사합니다. 전투 화면을 클릭하거나 `Esc`를 누르면 포인터 잠금을 전환할 수 있습니다.

## 오디오

- `audio-manager.js`가 효과음과 볼륨 상태를 관리합니다.
- `assets/title-hangar-bgm.mp3`는 타이틀/격납고 BGM입니다.
- `assets/audio/kenney/`에는 무기, 엔진, 폭발, 금속 충돌, 문, 추력 효과음이 있습니다.
- 브라우저 자동 재생 정책상 첫 사용자 입력 후 사운드가 활성화됩니다.

## 시각 설정

게임 내 **VISUAL SETTINGS**에서 다음 항목을 조절할 수 있습니다.

- 블룸과 노출
- 창문 색상, 투명도, 러프니스, 어두움
- 반사 프로브 강도 및 반사 표현
- 전장 포스트 이펙트

기본값은 블룸 `0.2`, 노출 `1.2`, 창문 러프니스 `0`, 창문 투명도 `0.9`, 창문색 `RGB(77, 132, 153)`, 반사 강도 `3`, 창문 어두움 `5.5`입니다.

## 프로젝트 구조

```text

├── index.html             # 게임 루프, UI, 격납고, 전장, 커스터마이저

├── weapon-system.js       # 무장 프로필 및 공통 수치
├── enemy-ai.js            # 적 메카 AI
├── mecha-rigidbody.js     # 메카 물리 보조
├── cannon-physics.js      # 탄피/물리 효과 보조
├── level1-map.js          # 레벨 1 맵 데이터
├── audio-manager.js       # 사운드 관리
├── run-server.bat         # Windows 로컬 서버 실행
└── assets/
    ├── title-hangar-bgm.mp3
    └── audio/kenney/      # Kenney 효과음 리소스
```

## 개발 참고

- `index.html`의 모듈 스크립트는 ES Module 문법을 사용합니다.
- `mecha-character.js`의 설정은 메카 생성 시 병합되며, 저장된 `mechaCustomization` 값이 기본값보다 우선할 수 있습니다.
- 메카 형상이나 기본 소켓을 확인할 때는 커스터마이저의 **RESET**을 사용하거나 브라우저 저장 데이터를 지운 뒤 확인합니다.
- 코드 수정 뒤에는 서버를 새로고침하고 필요하면 `Ctrl+F5`로 캐시를 무시합니다.
- 정적 문법 확인 예시:

```powershell
node --check mecha-character.js
```

`index.html`의 모듈 본문은 별도 스크립트 파싱 또는 브라우저 로드로 확인합니다. 문법 검사만으로 시각 연출·충돌·커스터마이저 결합이 완전히 검증되지는 않으므로 브라우저에서 함께 확인합니다.

## 변경 이력

### 2026-07-27 — 격납고 리프트, 소켓 동기화, 엄폐 유도

- 타이틀을 지하 원형 리프트 상승 연출로 변경하고 중앙 샤프트가 실제로 보이도록 바닥을 링 구조로 변경
- 타이틀 카메라를 격납고 상부 고정 시점으로 변경
- 원형 리프트 플레이트, 원형 경고 링·조명 링을 적용해 샤프트 가장자리 틈을 제거
- 무기 선택 격납고에서도 타이틀에서 열린 리프트 게이트를 유지
- 호밍 미사일의 미사일-목표 개별 시야 판정을 추가해 건물 엄폐 뒤 추적을 차단
- 볼 조인트와 파츠 스냅의 좌표 변환을 통일하고, 조인트 이동 시 연결 파츠를 실시간 동기화
- 파츠 선택 시 소유 조인트를 선택·동기화하도록 개선
- 슬롯 3/4의 중복 소켓 연결을 정리하고 좌·우 서브 무기 소켓으로 통합
- 백팩 조인트를 백팩 코어 중심으로 이전하고 중심 결합 조인트를 추가
- 플레이어와 CPU의 최대 HP·에너지·실드를 200으로 확장하고 HUD 비율 계산을 새 최대치에 맞춤
- 다리 부위 0% 시 보행·대시·점프·비행을 차단
- 팔 부위 0% 시 해당 팔과 무장 파츠를 탈락·폭발 처리하고 해당 측 무장을 비활성화
- 몸통 부위 0% 시 플레이어 메카를 즉시 전체 파괴 처리
- 선택 볼 조인트 숨김 상태를 커스터마이즈 저장값에 추가

### 이전 V5 기능 기반

- 4슬롯 무장 선택, 적 메카 AI, 도시 전장, 파괴 가능한 건물, 차량·환경 오브젝트
- 메카 부위 내구도, 방어막, 픽업, 부스트/점프/비행, 카메라 모드
- 커스터마이저 저장/복원, 색상 프리셋, 파츠별 소켓 편집
- 반사·창문·블룸·노출을 포함한 시각 설정과 Kenney 기반 효과음 관리
