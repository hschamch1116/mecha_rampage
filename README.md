## 🛠️ 메카 커스터마이즈 & 역관절 보행 튜닝 (Customization & Gait)

* **`WALK TEST ▶` 실시간 제자리 보행 테스트**: 커스터마이징 화면(`MECHA CUSTOM`)에서 버튼 하나로 메카를 실시간 제자리 보행시키며 보행 모션을 테스트할 수 있습니다.
* **`🦖 GAIT` 튜닝 패널**: 보행 속도, 보폭, 힙 스윙, 무릎 굽힘, 바운스, 허벅지/정강이 각도 및 롤/피치 수치를 실시간 슬라이더로 조정하고 테스트할 수 있습니다.
* **볼 조인트 편집**: 백팩, 양 팔, 서브 무기 소켓, 하체 링크의 위치 및 크기 조절.
* **통합 좌표계 스냅 연산**: 모든 파츠 스냅은 `Player Local → World → Part Parent Local` 변환 과정을 거쳐 처리되므로 서로 다른 부모 계층을 가진 파츠도 동일한 기준 좌표로 결합됩니다.
* **자동 저장 & JSON 내보내기 (`SAVE FILE` / `LOAD FILE`)**: 현재 설정한 메카 커스터마이즈 셋팅을 브라우저 `localStorage`에 자동 보관하거나 `mecha-preset.json` 파일로 내보내어 관리할 수 있습니다.

## 💥 부위 내구도 & 전장 파괴 물리 (Damage & Destruction)

플레이어와 적 메카는 **최대 HP 200, 실드 200, 에너지 200**을 보유하며, **부위별 내구도 System**이 적용됩니다.

* **다리(Leg) 파괴 (HP 0%)**: 지면 보행, 부스트 대시, 점프가 차단되며 **하체 차체 회전(Rotation)까지 완전 잠금(Lock)**되어 이동 및 차체 회전이 완전 무력화됩니다. (상체 피벗 조준만 가능)
* **팔(Arm) 파괴 (HP 0%)**: 해당 측면의 팔 파츠가 유닛에서 탈락·폭발하며, 장착된 무기 발사가 비활성화됩니다.
* **몸통(Torso) 파괴 (HP 0%)**: 메카 유닛 전체가 폭발 파티클과 함께 파괴 처리됩니다.
* **2D 원형 스플래시 & 건물 파괴**: 폭발 시 2D 수평 원형 반경(`getRadialFalloff`) 스플래시 연산이 적용되어 주변 건물 27m 유리창이 산산조각나며 표면 블록이 파손됩니다.
* **밝은톤 그레이 분진 스모그**: 건물 붕괴 시 화려하고 웅장한 **밝은 라이트 그레이 톤 분진 먼지 구름**(`0xe8e4df`, `0xd8d4cf`) 및 거대한 낙하 폭발 충격파가 연출됩니다.

### Windows 실행 (권장)

프로젝트 루트 폴더의 `run-server.bat`을 실행하거나 PowerShell / CMD에서 다음 명령을 실행합니다.

```powershell
# Python 3가 설치되어 있는 경우
py -m http.server 8080
```

서버 실행 후 브라우저 주소창에 **[http://localhost:8080](http://localhost:8080)** 접속.

> ⚠️ `file://` 직접 로드 방식은 브라우저의 CORS 및 Audio API 제한이 발생할 수 있으므로, 상기 로컬 HTTP 서버 실행을 강력히 권장합니다.

## 최근 기능 보완

기존 게임 흐름과 시스템은 유지하면서 다음 기능을 보완했습니다.

- **콕핏과 전면부**
  - 전면 창 뒤쪽의 여러 겹 메쉬가 콕핏을 가리지 않도록 내부를 단순한 박스형 구조로 정리했습니다.
  - 콕핏은 메카 전면에서 살짝 돌출된 다각형 형태로 만들고, 위·아래·좌·우 덮개 메쉬를 추가해 틈으로 내부가 뚫려 보이지 않도록 했습니다.
  - 유리의 투명도만 높이는 방식에 의존하지 않고 창 뒤의 좌석, 파일럿, 콘솔, 백플레이트가 보이는 순서를 함께 조정했습니다.
  - 격납고 UI의 **Cockpit Camera** 버튼으로 일반 격납고 카메라와 콕핏 시점을 전환할 수 있습니다.

- **격납고 반사와 조명**
  - 격납고 전용 256×256 반사 프로브를 사용해 주변 구조물과 바닥 반사를 별도로 관리합니다.
  - 프로브는 콕핏 기준 전방 10m 위치를 기준으로 배치할 수 있습니다.
  - 일반 격납고 조명은 활성화 여부, 밝기, 범위, 색상, point/spot/all 타입을 조절할 수 있습니다.
  - 경고등은 메쉬 색상만 바꾸는 방식이 아니라 실제 회전형 레드 스포트라이트와 발광 메쉬를 분리해 관리합니다.
  - 경고등 범위는 최대 100까지 설정할 수 있고, 메카 중심 라이트는 파워 10·범위 40을 기준으로 조절할 수 있습니다.
  - 메카 라이트의 색상과 위치를 별도로 지정해 메카 중심부를 밝히면서 격납고 전체 조명과 섞이지 않도록 했습니다.

- **Visual Settings와 설정 복사**
  - `reflectionIntensity`, `windowDarkness`, `windowColor`, `windowOpacity`, `windowRoughness`를 창문·반사 표현과 함께 관리합니다.
  - `bloomStrength`와 `toneExposure`로 후처리 밝기를 조절하고, 조명을 모두 끈 상태에서 불필요한 발광이 남는지 확인할 수 있습니다.
  - `rainIntensity`, 안개 모드, 안개 색상, 밀도, near/far, 증기·더스트 강도를 한 번에 저장합니다.
  - `hangarLights` 아래에 전체 조명, 경고등, 메카 라이트, 추가 라이트 설정을 보관합니다.
  - **Copy Config**를 사용하면 화면의 모든 비주얼 항목을 하나의 JSON으로 복사해 메모장에 저장하거나 다른 실행 환경에 붙여넣을 수 있습니다.
  - 슬라이더, 색상 입력, 체크박스 변경이 즉시 런타임 객체에 반영되며, 초기 진입 시에도 설정값을 먼저 읽는 것을 기준으로 합니다.

- **메카 외형과 허벅지 디테일**
  - 허벅지에 외장 패널, 세로 레일, 볼트, 힌지, 통풍구, 유압 실린더와 연결부를 추가했습니다.
  - 기존 실루엣과 관절 가동 범위를 침범하지 않도록 장식 파츠를 본체에 밀착 배치했습니다.
  - 모든 모서리를 고해상도로 라운딩하지 않고, 실루엣에 영향을 주는 큰 모서리만 완화해 메쉬 비용을 제한했습니다.
  - 무기 슬롯 변경 시 어깨 파츠가 사라지지 않도록 무기 본체와 어깨 장갑의 표시 상태를 분리합니다.

- **무기 장착 및 발사 연출**
  - 레이저 무기의 빔과 장착 파츠 사이 Z-fighting을 줄이고, 레이저가 메카 바디를 부자연스럽게 관통하지 않도록 투사 깊이를 조정했습니다.
  - 개틀링은 은색 탄과 연결 띠를 사용하며, 탄띠 방향을 90도 회전하고 아래로 더 길게 늘어뜨려 장착감을 높였습니다.
  - 탄과 탄 사이 연결부가 끊기거나 끝부분이 따로 떨어져 보이지 않도록 연결 간격과 끝단 고정을 맞췄습니다.
  - 호밍 미사일은 발사 전에도 랙에 장착된 상태가 보이며, 발사할 때마다 일정 각도로 회전해 리볼버식 순환 장착 연출을 냅니다.
  - 헤비 캐논은 발사 순간 포신과 총구가 뒤로 당겨지는 반동을 적용해 발사 피드백을 강화했습니다.

- **건물 내부와 시민 대피**
  - 1층 로비에는 앉아 있는 시민, 책상, 의자를 배치하고 메카가 잘 보이는 일부 층에도 간헐적으로 실내 소품을 배치했습니다.
  - 건물 피격 시 무작위 위치가 아니라 해당 건물 전면의 실제 입구를 대피 시작점으로 사용합니다.
  - 한 명씩 순차적으로 생성하는 대신 입구에서 여러 시민이 짧은 시간에 함께 나오도록 해 공격 직후의 혼란을 표현합니다.
  - 시민은 상의, 하의, 헬멧, 가방 색상을 조합해 여러 종류의 옷을 입은 것처럼 표시합니다.
  - 격납고의 정비·보행 인원과 전장의 건물 대피자는 서로 다른 역할과 배치 규칙을 사용합니다.

- **파티클과 충돌 연출**
  - 용접 스파크는 큰 원형 파티클 대신 작고 짧은 스프레이 입자로 구성해 카메라 이동 시 공간감을 유지합니다.
  - 한 번에 많이 튀긴 뒤 일정 시간 쉬는 간헐적 발생 패턴을 사용합니다.
  - 입자는 한 지점으로만 떨어지지 않고 여러 방향으로 흩어지며, 바닥에 한 번 바운스한 뒤 소멸합니다.
  - 격납고 오브젝트와의 충돌을 고려해 오른쪽 상단에서 발생한 스파크가 공중을 그대로 관통하지 않도록 했습니다.
  - 더스트 파티클은 작고 은은하게 분산시켜 카메라가 움직일 때만 깊이감이 느껴지도록 조정합니다.

- **발광·유리·재질 점검 기준**
  - 격납고 메쉬는 메카와 레이저를 제외하고 불필요한 `emissive`와 `emissiveIntensity`를 제거하는 방향으로 관리합니다.
  - 엘리베이터 링, 층수 표시, 난간, 로봇암, 모니터 패널, 바닥 라인, 유리 재질도 일반 재질인지 함께 확인합니다.
  - 발광처럼 보이는 현상은 emissive뿐 아니라 높은 알파값, Bloom, 스포트라이트, 반사 프로브, 밝은 기본 색상도 함께 확인합니다.
  - 유리 메시가 뒤쪽 파츠를 가리거나 겹쳐 보이는 경우 투명도, 렌더 순서, 깊이 테스트, 내부 백플레이트를 함께 점검합니다.

- 시간대에 따라 하늘 그라디언트, 안개 색상, 태양 색상, 광원 방향, 광원 세기, 림 라이트, 원경 구름 색상이 보간됩니다.

- 설정값은 `mechaVisualSettings`의 `battlefieldTimeOfDay`, `battlefieldEnvironmentColor`에 저장됩니다.
- 시각 설정 JSON 복사, 불러오기, 초기화에도 전장 분위기 설정을 포함합니다.

- `cloudLayers`

### 건물 그림자 최적화

건물 상세 메쉬 전체가 그림자 처리에 참여하지 않고, 건물마다 하나의 저폴리 계단형 실루엣 메쉬만 그림자를 생성하도록 변경했습니다.

- `createBuildingShadowProxy()`가 기존 건물의 층수와 테이퍼형 실루엣을 기준으로 그림자 프록시를 생성합니다.
- 건물 코어, 지붕, 기둥, 파사드 상세, 투명 창문 배치는 그림자를 생성하지 않습니다.
- 프록시는 색상 출력을 비활성화한 재질을 사용하므로 화면에는 보이지 않고 그림자 맵에만 참여합니다.
- 해당 건물의 붕괴가 시작되면 프록시도 숨겨져, 붕괴 후 온전한 타워 그림자가 남지 않습니다.
- 충돌, 체력, 파사드 창문 파괴, 붕괴 게임플레이는 기존 `registerBlock()` 및 건물 시스템이 계속 담당합니다.
